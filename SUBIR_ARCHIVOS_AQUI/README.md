# Carpeta auxiliar para archivos

Esta carpeta se conserva para organización. Los instaladores APK pueden subirse directamente a la **raíz** del repositorio.

Para archivos de más de 25 MB, no uses la carga web de GitHub. Configura Git LFS y súbelos desde Git o Termux siguiendo las instrucciones del [README principal](../README.md).

Los formatos Android configurados con Git LFS son: `.apk`, `.aab`, `.apks`, `.xapk` y `.obb`.
